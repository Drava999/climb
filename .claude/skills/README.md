# Design skills used for Climb

Downloaded 2026-10-16 to guide Climb's interface design. Each folder keeps its original licence.

| Skill | Source | Version | Used for |
|---|---|---|---|
| `impeccable` | https://github.com/pbakaus/impeccable (Apache 2.0) | 5bf0a06 | App-UI ("Operate" mode) craft floor: contrast, states, browser surfaces, no eyebrow labels |
| `emil-design-eng`, `mobile-native`, `apple-design`, `animate`, `review-animations` | https://github.com/emilkowalski/skill (MIT) | 2d22863 | Motion, press feedback, easing, making a web app feel native on a phone |
| `taste-skill` | https://github.com/Leonxlnx/taste-skill (MIT) | f624f37 | Anti-template rules: one ground, one ink, one accent; no tiny uppercase labels; no stock palettes |

The skills' own scripts (launchers, inspectors) are not run by the site and are not part of the deployed app (only `public/` is served).
